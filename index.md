# Omarchy rclone Google Drive Integration

This is a personal application used to access Google Drive from an Omarchy Linux desktop using [rclone](https://rclone.org/).

## Purpose

The application enables its owner to mount Google Drive as a local filesystem for personal file management and automation.

## Google Drive Access

The application requests Google Drive permissions to read, create, modify and delete files as directed by its owner.

It is not offered as a public service and does not provide access to other users.

## Privacy

See the [Privacy Policy](privacy.html) for information about how Google account data is handled.
