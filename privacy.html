Privacy Policy

Omarchy rclone is a personal application used to access Google Drive from a Linux desktop through rclone.

Data Access

The application requests Google Drive permissions to read, create, modify and delete files as directed by the account owner.

Data Storage

OAuth credentials are stored locally in the rclone configuration. File contents and metadata may be cached locally to support filesystem operations.

Data Sharing

The application communicates with Google Drive through Google's APIs. It does not operate an independent server that collects or sells user data.

Data Retention and Revocation

The account owner controls local credentials and cached data. Google account access can be revoked through Google Account security settings.

Application Availability

This integration is intended exclusively for personal use and is not offered as a public service.
